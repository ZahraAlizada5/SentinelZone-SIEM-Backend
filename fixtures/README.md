# Test fixtures

These files are supplied synthetic/redacted payloads used by the preserved regression tests. Private-range IP literals, host labels, event IDs and timestamps are fixture data, not configuration for the recipient's machine. The Cowrie password is a redacted marker. No deployable credential is supplied.

Fixture ingestion requires explicit development/test opt-in and produces TEST events, degraded connector status, and incomplete telemetry. It never proves live connectivity. Do not replace these fixtures with unredacted lab exports. Owner confirmation of fixture provenance is part of the pending licensing review.
